# APDO v0.4.0 Delivery

Release target: `v0.4.0` of the Automatic PyTorch DataLoader Optimizer (`apdo`).

## Scope delivered

`v0.4.0` focuses on measurement honesty and recommendation stability:

- **Lifecycle timing.** Loader trials record construction, iterator initialization, first-batch acquisition, execution, worker shutdown, loader cleanup, and total trial wall as separate fields.
- **Two selection metrics.** `sustained` (default) ranks steady-state execution throughput; `amortized` divides all trial samples by the complete trial wall.
- **Timing profiles.** `standard` uses whole-cycle CUDA Events; `detailed` adds transfer and per-step device events without per-batch synchronization.
- **Batch comparability.** Batch structure and optional sample fingerprints feed `off` / `warn` / `strict` diagnostics; `strict` requires verified sample identity.
- **Stability evaluation.** `evaluate_stability` and `apdo stability` repeat independent optimizations, retain partial failures, and summarize agreement, gain intervals, throughput spread, and failure coverage.
- **Reports.** JSON schema version 4 and protocol version 4.0, with lifecycle, timing, and comparability sections in JSON and HTML.
- **Workloads.** Six deterministic local workloads: in-memory, disk-backed, cpu-heavy, startup-bound, compute-bound, and a real training workload.

Public defaults are unchanged: loader mode one epoch, training mode three epochs, three training finalists, two training rounds, `minimum` validation policy, safe initial fallback. Protocol and schema numbers moved from 3.0/v3 to 4.0/v4.

## Known limitations carried into this release

- Comparability fingerprints only detect differences they are given; arbitrary dataset or transform state cannot be proven equivalent.
- Detailed CUDA event timing can perturb very short transfers or steps.
- `max_ram_gb` remains a sampled, advisory guard.
- Map-style datasets only; single-device training; macOS not covered by CI.
- Benchmark results are machine-specific; the recorded run used CPU measurement on one Windows laptop.
