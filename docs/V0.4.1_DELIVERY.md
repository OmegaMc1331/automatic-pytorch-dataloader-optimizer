# APDO v0.4.1 Delivery

Release target: `v0.4.1` of the Automatic PyTorch DataLoader Optimizer (`apdo`).

`v0.4.1` is a reliability hotfix for `v0.4.0`. It does not add a new benchmark mode, does not change the JSON schema version, and does not change public defaults other than the validation round count.

## Scope

- **Validation.** Eight-pair minimum, exact one-sided paired sign test at `alpha = 0.05`, explicit invalid-observation rejection, and audit-friendly budget truncation.
- **Selection consistency.** `sustained` and `amortized` flow through the same helpers for worker finalists, training candidates, selection, ranking, JSON, text, and HTML.
- **Stability honesty.** Confirmed gains, fallbacks, initial retention, candidate agreement, and insufficient-validation warnings are reported separately.
- **Workloads.** Startup-bound exercises multiple loader epochs; compute-bound runs real MLP training over cheap input.
- **Protocol.** Benchmark protocol moves from 4.0 to 4.1. JSON schema remains version 4.
- **Defaults.** `validation_rounds` moves from 5 to 10 in the Python API, CLI, and benchmark/stability scripts. Lower values remain accepted but cannot confirm without eight valid pairs.
- **Documentation.** README, CHANGELOG, examples, baseline audit, benchmark report, and this delivery record are updated.

No source comments, placeholders, optional heavy dependencies, or v0.5.0 work were added. PyPI publication is not part of this release.

## Compatibility

- Python 3.10 through 3.14 remain supported.
- Existing `optimize()` calls remain source-compatible.
- JSON schema version remains 4.
- Protocol version is 4.1.
- Callers that relied on confirming from fewer than eight pairs will now receive `not_possible`; this is the intended reliability fix.
- Callers that explicitly passed `validation_rounds` keep their value, but values below eight cannot confirm.

## Known limitations

- The exact sign test is conservative for small samples; eight successes out of ten observations cannot reach `p < 0.05`.
- A single strong outlier can move the median and bootstrap interval; the sign test protects the decision but may produce `inconclusive` rather than `confirmed`.
- The memory limit remains sampled and advisory.
- macOS is not covered by CI in this release.
- Benchmark numbers are machine-specific and are not performance guarantees.
